## 🎨 Design System

### Colors
| Token | Hex | Usage |
|-------|-----|-------|
| Gold | `#d4af37` | Primary accent, headings |
| Cyan | `#00d4ff` | Secondary accent, highlights |
| Dark | `#0a0a0f` | Background |
| Card | `#1a1a2e` | Card backgrounds |

### Typography
- **Headings**: Cinzel (serif, elegant)
- **Body**: Inter (clean, modern)
- **Accents**: Orbitron (futuristic, tech)
